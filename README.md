# SELA · подарочный сертификат

Кликабельный адаптивный прототип покупки подарочного сертификата. Проект сделан на React и Vite, слайдер — на `morphing-scroll`.

## Запуск

Понадобится Node.js 20 или новее.

```bash
npm install
npm run dev
```

После запуска откройте адрес, который Vite покажет в терминале. Обычно это [http://localhost:5173](http://localhost:5173).

## Другие команды

```bash
npm run dev:open  # запустить проект и открыть браузер
npm run build     # собрать production-версию
npm run preview   # посмотреть production-сборку локально
npm run check     # проверить сборку
```

## Что можно проверить

- выбор дизайна сертификата;
- заполнение открытки и анонимная отправка;
- данные получателя и отправка по расписанию;
- проверка заказа и выбор оплаты;
- экран ожидания оплаты с QR-кодом и таймером;
- обратная навигация по степперу и кнопке «Вернуться»;
- desktop- и mobile-версии.

Это визуальный прототип: данные хранятся локально, реальная оплата и отправка сертификата не выполняются.
